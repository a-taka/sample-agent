# 生成AIにおけるファイルベースRAGとプロンプト設計

- **Tags**: Generative AI, RAG, Markdown, Prompt Engineering

## 概要
RAG（Retrieval-Augmented Generation：検索拡張生成）は、LLM（大規模言語モデル）の回答生成時に外部ナレッジを参照させることで、ハルシネーションを抑制し最新情報や固有知識に基づいた回答を実現する手法です。

## ファイルベースRAGの特徴
- **VectorDB 不要のシンプル構成**: ナレッジ件数が小〜中規模の場合、知識を構造化された Markdown ファイル（`.md`）として保存し、キーワード検索・全文検索で関連ファイルを抽出する「ファイルベースRAG」が有効です。
- **高い可読性とメンテナンス性**: Markdown 形式（見出し・箇条書き・タグ）で保存することで、人間が直接 Git で差分管理・レビューでき、LLM にとっても文脈構造を把握しやすくなります。
- **トピックガードレール**: ナレッジ蓄積時に「生成AIに関連する情報か」を判定する分類ステップを挟むことで、無関係な雑談や対象外ドメインの情報がナレッジベースに混入するのを防ぎます。
