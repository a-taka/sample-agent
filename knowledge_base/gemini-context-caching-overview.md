# Gemini Context Cachingの概要とメリット

- **Tags**: Gemini, Context Caching, Cost Optimization

## 内容
GeminiのContext Caching（コンテキストキャッシュ）機能を利用することで、大規模なシステムプロンプトや頻繁に参照される長大なドキュメントを事前にキャッシュできます。

## 主なメリット
- **トークンコストの削減**: キャッシュされたコンテキストを再利用することで、リクエストごとの入力トークン費用を大幅に抑えられます。
- **レイテンシの短縮**: 大量のテキストを再送信・再処理するオーバーヘッドが減少し、レスポンス速度が向上します。
