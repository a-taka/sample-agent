# Agent Spec

## Overview
`smart-knowledge-agent` is an ADK 2.0 Graph `Workflow` agent that manages and retrieves knowledge exclusively about **Generative AI (生成AI)**. It evaluates incoming user messages to determine:
1. Whether the topic is related to Generative AI (LLM, prompting, RAG, AI agents, fine-tuning, multimodal AI, Vertex AI / Gemini, etc.).
2. Whether the user is providing reusable knowledge to store (`save_knowledge`) or asking a question to be answered using stored knowledge (`query_knowledge`).

If the input is Generative AI knowledge, the workflow extracts and saves it as a structured Markdown file (`knowledge_base/<slug>.md`). If the input is a Generative AI question, the workflow searches existing Markdown files in `knowledge_base/` (file-based RAG without an external VectorDB) and answers based on the retrieved documents. If the input is **not** related to Generative AI, a strict guardrail route (`non_genai`) prevents any file creation and declines to answer the off-topic question.

## Language
`python` (`google-adk >= 2.0.0`, Graph `Workflow` API)

## Architecture & Workflow Topology
```
START
  └─> classify_input (LlmAgent with Pydantic output_schema)
        └─> route_by_classification (FunctionNode emitting Event with route)
              ├─ route="save_knowledge"  ─> save_knowledge_markdown (FunctionNode: writes knowledge_base/<slug>.md & responds)
              ├─ route="query_knowledge" ─> retrieve_markdown_files (FunctionNode: searches knowledge_base/*.md)
              │                               └─> rag_answer_agent (LlmAgent: answers using retrieved Markdown content)
              └─ route="non_genai"       ─> decline_non_genai (FunctionNode: no file written, polite refusal response)
```

- **Entry Point (`START`)**: Receives the user input.
- **Classifier Agent (`classify_input`)**: An `LlmAgent` with a Pydantic `output_schema` (`KnowledgeClassification`) that determines:
  - `is_genai_related: bool` — `True` only if the input is about Generative AI, LLMs, AI agents, RAG, prompt engineering, or related AI technologies.
  - `intent: Literal["save_knowledge", "query_knowledge", "non_genai"]` — Classification of the user's intent.
  - `title: str` / `slug: str` / `markdown_body: str` — Structured Markdown content extracted when `intent == "save_knowledge"`.
  - `search_keywords: list[str]` — Keywords extracted for file search when `intent == "query_knowledge"`.
- **Router Node (`route_by_classification`)**: A `FunctionNode` that enforces the guardrail (`if not is_genai_related: route = "non_genai"`) and emits `Event(output=..., route=route)`.
- **Markdown Saver Node (`save_knowledge_markdown`)**: Routed to on `"save_knowledge"`. Saves the formatted Markdown file under `knowledge_base/<slug>.md` and emits a confirmation message with the saved file name and summary.
- **Markdown Retriever Node (`retrieve_markdown_files`)**: Routed to on `"query_knowledge"`. Searches all `*.md` files in `knowledge_base/` by matching keywords and content, returning the top matching Markdown documents alongside the user's question.
- **RAG Answer Agent (`rag_answer_agent`)**: An `LlmAgent` (with `output_schema`) that answers the user's Generative AI question grounded in the retrieved Markdown files (citing the source `.md` file names).
- **Non-GenAI Guard Node (`decline_non_genai`)**: Routed to on `"non_genai"`. Performs **no file I/O** and returns a polite refusal stating that this agent only saves knowledge and answers questions related to Generative AI.

## Example Use Cases
1. **Saving Generative AI Knowledge (`save_knowledge`)**:
   - **Input**: "ADK 2.0のGraph Workflowでは、LlmAgentにoutput_schema（Pydanticモデル）を設定することで後続ノードに型安全なデータを渡せる。またEvent(route='...')を返すことで条件分岐エッジを実現できる。"
   - **Route**: `START` -> `classify_input` -> `route_by_classification` (`route="save_knowledge"`) -> `save_knowledge_markdown`
   - **Expected Output**: Saves a Markdown file (e.g., `knowledge_base/adk-2-0-graph-workflow.md`) and replies confirming the file was saved with its title and summary.
2. **Querying Stored Generative AI Knowledge (`query_knowledge` - File RAG)**:
   - **Input**: "ADK 2.0のGraph Workflowで条件分岐や型安全なデータ受け渡しはどうやりますか？"
   - **Route**: `START` -> `classify_input` -> `route_by_classification` (`route="query_knowledge"`) -> `retrieve_markdown_files` -> `rag_answer_agent`
   - **Expected Output**: Searches `knowledge_base/*.md`, retrieves the saved ADK 2.0 note, and explains `output_schema` and `Event(route=...)` citing the saved Markdown file.
3. **Rejecting Non-GenAI Knowledge Input (`non_genai`)**:
   - **Input**: "美味しいカレーの作り方のナレッジです。玉ねぎを飴色になるまで30分炒めると甘みが出ます。これを保存してください。"
   - **Route**: `START` -> `classify_input` -> `route_by_classification` (`route="non_genai"`) -> `decline_non_genai`
   - **Expected Output**: Does **not** create any Markdown file in `knowledge_base/`, and replies that only Generative AI topics are supported.
4. **Rejecting Non-GenAI Question (`non_genai`)**:
   - **Input**: "明日の東京の天気やおすすめの観光スポットを教えてください。"
   - **Route**: `START` -> `classify_input` -> `route_by_classification` (`route="non_genai"`) -> `decline_non_genai`
   - **Expected Output**: Does **not** answer the question about weather/tourism and does **not** create any file; politely informs the user that it only answers questions related to Generative AI.

## Tools & Storage Required
- **Local Markdown Knowledge Base (`knowledge_base/`)**: Standard Python `pathlib` file read/write operations inside the workflow nodes (`save_knowledge_markdown` and `retrieve_markdown_files`). No external VectorDB or third-party API required.
- Sanitizes file slugs (`[a-z0-9-_]+.md`) to prevent path traversal outside `knowledge_base/`.

## Constraints & Safety Rules
- **Strict GenAI Topic Guardrail**: Any input unrelated to Generative AI must route to `"non_genai"`, must **never** write a Markdown file, and must **never** answer the off-topic question.
- **Path Safety**: Markdown filenames must be strictly sanitized and confined to the `knowledge_base/` directory.
- **Typed Workflow Nodes**: All `LlmAgent` nodes inside the `Workflow` must define a Pydantic `output_schema`, and user-facing `FunctionNode`s must emit `Event(content=...)` so outputs render properly in ADK Web UI and CLI.

## Success Criteria
- **Guardrail Accuracy**: 100% of non-Generative-AI inputs (both knowledge statements and general questions) route to `decline_non_genai` with zero files written.
- **Knowledge Persistence & File-RAG Accuracy**: 100% of Generative AI knowledge inputs create a `.md` file in `knowledge_base/`, and subsequent Generative AI questions retrieve and reference the stored Markdown content.
- **Evaluation Metrics**: Passes `final_response_quality` and `safety` evaluation metrics in `agents-cli eval run`.
